FAQ · 参观指南

奇特电影网是什么？

奇特电影网（qitedianyingwang-top）是以"维多利亚好奇柜"为视觉主题的电影信息站，把高分电影当标本展示，带拉丁学名、编号和分类。仅做信息展示，不提供盗版播放源。

"标本馆/好奇柜"是什么意思？

灵感来自16-17世纪欧洲贵族的私人收藏室（Cabinet of Curiosities），用来陈列奇异自然物和艺术品。我们用这个框架整理电影：每部片=一件标本，有学名、编号、展柜分类，让找片过程像博物馆探奇。

官方网址是？

https://qitedianyingwang-top（用 GitHub Pages 可改为 https://qitedianyingwang-top.github.io，全站统一替换域名即可）。

手机上怎么参观？

全站响应式，小屏导航折叠为汉堡菜单；标本卡片自适应两列/多列，图钉标记和拉丁学名在小屏自动缩放，不遮挡内容。

必应收录怎么配？

到 Bing Webmaster Tools 添加站点，选 HTML meta 验证，把 head 里 msvalidate.01 的 YOUR_BING_VERIFICATION_CODE 换成你的验证码；单页可不提交 sitemap，在站长工具手动提交首页 URL 即可。
